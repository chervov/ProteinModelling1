## 1. Introduction & Theoretical Motivation

When evaluating the impact of protein missense variants, running full-atom Monte Carlo conformational sampling (such as **Rosetta `cartesian_ddg`**) or empirical forcefield rotamer repacking (such as **FoldX 5.0**, whose values in this repository come from AlphaFold models via EBI ProtVar) on every variant can require significant computational resources.

For exploratory analysis, an analytical **Theoretical Biophysical $\Delta\Delta G$ Approximation Model** was formulated to decompose the free energy change of unfolding into fundamental physical terms:

$$\Delta\Delta G_{\text{est}} = \Delta G_{\text{mutant}} - \Delta G_{\text{wild-type}} \quad (\text{kcal/mol})$$

### Intended Sign Convention:
* **$\Delta\Delta G > 0$:** Destabilizing.
* **$\Delta\Delta G < 0$:** Stabilizing *(Note: As detailed in the audit note above, this model cannot predict negative values)*.
* **$\Delta\Delta G \approx 0$ ($< 0.8\text{ kcal/mol}$):** Neutral / within physiological thermal fluctuation.

---

## 2. Mathematical Component Decomposition (Textbook Framework)

The total estimated free energy perturbation was proposed as a linear combination of physical energetic terms:

$$\Delta\Delta G_{\text{approx}} = \Delta\Delta G_{\text{steric}} + \Delta\Delta G_{\text{elec}} + \Delta\Delta G_{\text{cavity}} + \Delta\Delta G_{\text{backbone}}$$

### 2.1 Steric Clash Penalty ($\Delta\Delta G_{\text{steric}}$)
When a smaller amino acid is replaced by a larger one ($\Delta V = V_{\text{mut}} - V_{\text{wt}} > 0$) in a buried environment:
$$\Delta\Delta G_{\text{steric}} = \alpha \cdot \Delta V \cdot \Omega_{\text{burial}} + \Delta\Delta G_{\text{Gly\_penalty}}$$

* $\alpha \approx 0.040\text{ kcal/mol/\AA}^3$ (empirical overlap coefficient assuming rigid unrelaxed coordinates).
* $\Omega_{\text{burial}} \in [0.0, 1.0]$: Fractional burial index.
* **The Glycine Rule ($\Delta\Delta G_{\text{Gly\_penalty}}$):** Glycine occupies unique Ramachandran dihedral space. Replacing Gly in a tight turn with a bulky residue incurs a severe steric and torsional barrier ($+1.5\text{ to }+2.5\text{ kcal/mol}$).

### 2.2 Hydrophobic Cavity Creation ($\Delta\Delta G_{\text{cavity}}$)
When a bulky hydrophobic residue is replaced by a smaller residue ($\Delta V < 0$) in the protein interior:
$$\Delta\Delta G_{\text{cavity}} = \kappa \cdot |\Delta V| \cdot \Omega_{\text{burial}}$$

* $\kappa \approx 0.024\text{ kcal/mol/\AA}^3$ (the Eriksson–Matthews cavity coefficient from T4 lysozyme mutagenesis, *Science* 1992).

### 2.3 Electrostatic & Charge Desolvation Penalty ($\Delta\Delta G_{\text{elec}}$)
Transferring an unshielded charged group into a low-dielectric core incurs a Born desolvation penalty.

### 2.4 Backbone Dihedral & Proline Rigidity ($\Delta\Delta G_{\text{backbone}}$)
* **Proline $\to$ Other:** Loss of the cyclic pyrrolidine ring introduces entropic laxity.
* **Other $\to$ Proline:** Incurs backbone dihedral angle strain unless accommodated by local geometry.

## 4. Historical Python Implementation

```python
"""
Historical Implementation of the Heuristic Delta-Delta-G Approximator.
WARNING: DEPRECATED — FAILED EMPIRICAL VALIDATION. DO NOT USE FOR SCORING OR RANKING.
"""

class BiophysicalDDGApproximator:
    def __init__(self):
        self.alpha = 0.040        # Steric clash coefficient (kcal/mol / A^3)
        self.kappa = 0.024        # Cavity coefficient (kcal/mol / A^3)
        self.gly_penalty = 2.42   # Glycine tight-turn disruption penalty
        self.born_penalty = 1.42  # Desolvation penalty for buried charges
        self.pro_penalty = 1.45   # Proline cyclic rigidity loss penalty

        self.aa_volumes = {
            'G': 60.1,  'A': 88.6,  'S': 89.0,  'C': 108.5, 'D': 111.1,
            'P': 112.7, 'N': 114.1, 'T': 116.1, 'E': 138.4, 'V': 140.0,
            'Q': 143.8, 'H': 153.2, 'M': 162.9, 'I': 166.7, 'L': 166.7,
            'K': 168.6, 'F': 189.9, 'Y': 193.6, 'W': 227.8, 'R': 225.0
        }

        self.aa_charges = {
            'D': -1.0, 'E': -1.0, 'K': 1.0, 'R': 1.0, 'H': 0.1,
            'G': 0.0, 'A': 0.0, 'S': 0.0, 'C': 0.0, 'P': 0.0,
            'N': 0.0, 'T': 0.0, 'V': 0.0, 'Q': 0.0, 'M': 0.0,
            'I': 0.0, 'L': 0.0, 'F': 0.0, 'Y': 0.0, 'W': 0.0
        }

    def compute_ddg(self, wt, mut, burial_index=0.8, is_tight_turn=False,
                    is_salt_bridge=False, is_catalytic_core=False,
                    is_autoinhibitory_switch=False):
        v_wt = self.aa_volumes.get(wt, 140.0)
        v_mut = self.aa_volumes.get(mut, 140.0)
        delta_v = v_mut - v_wt

        q_wt = self.aa_charges.get(wt, 0.0)
        q_mut = self.aa_charges.get(mut, 0.0)
        delta_q = abs(q_mut) - abs(q_wt)

        # Steric Clash
        ddg_steric = 0.0
        if delta_v > 0:
            ddg_steric += self.alpha * delta_v * burial_index
            if is_autoinhibitory_switch:
                ddg_steric += 1.2

        if wt == 'G' and mut != 'G':
            ddg_steric += self.gly_penalty if is_tight_turn else 1.2

        # Cavity
        ddg_cavity = 0.0
        if delta_v < 0:
            ddg_cavity += self.kappa * abs(delta_v) * burial_index
            if wt in ['F', 'Y', 'W'] and mut in ['A', 'V', 'G', 'S']:
                ddg_cavity += 1.1

        # Electrostatics
        ddg_elec = 0.0
        if delta_q > 0:
            if burial_index > 0.5:
                ddg_elec += self.born_penalty * burial_index
            if is_catalytic_core:
                ddg_elec += 1.0

        if is_salt_bridge and abs(q_wt) > 0 and q_mut == 0:
            ddg_elec += 2.2

        # Backbone
        ddg_backbone = 0.0
        if wt == 'P' and mut != 'P':
            ddg_backbone += self.pro_penalty
        elif wt != 'P' and mut == 'P':
            ddg_backbone += 1.8 if is_catalytic_core else 1.2

        # Aliphatic isomer mitigation
        if wt in ['V', 'I', 'L'] and mut in ['V', 'I', 'L']:
            ddg_steric = min(ddg_steric, 0.4)
            ddg_cavity = min(ddg_cavity, 0.4)

        ddg_total = ddg_steric + ddg_cavity + ddg_elec + ddg_backbone
        return round(ddg_total, 2)
```

## 6. Conclusions & Deprecation

1. **Retraction for Variant Ranking:** The heuristic approximator must **not** be used for predicting thermodynamic stability, variant classification, or clinical ranking. Real structural methods (FoldX, ThermoMPNN, Rosetta, DDMut) must be used instead.
2. **Clarification on AlphaGenome:** AlphaGenome is a regulatory and functional genomics model predicting sequence effects on epigenomic and transcriptomic tracks. It does **not** evaluate missense protein thermodynamic stability.
3. **Refutation of Naive Domain Rules:** Deterministic rules assigning GOF/LOF solely based on domain (e.g. "JH2 $\implies$ GOF, JH1 $\implies$ LOF") are contradicted by deep mutational scanning data and must be avoided.
