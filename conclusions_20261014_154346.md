# What we learnt — JAK1 / JAK2 OpenFold guided recycling (20261014_154346)

| Run | Result |
|---|---|
| JAK1, shallow MSA (32/64), no template (earlier runs, e.g. [JAK1_20261013_192228](JAK1/runs/JAK1_20261013_192228)) | JH1 stays near FERM, low pLDDT; never closer than 61.5 Å to open |
| JAK1, whole MSA (512/8192), no template ([JAK1_20261014_115803](JAK1/runs/JAK1_20261014_115803)) | **open** (ma-a1sai-like, 1.0–2.3 Å) |
| JAK1, AF2 template ([JAK1_20261014_095758](JAK1/runs/JAK1_20261014_095758)) | open, copies the AF2 model |
| JAK2, AF2 template ([JAK2_20261014_095758](JAK2/runs/JAK2_20261014_095758)) | open, copies the AF2 model |
| JAK2, JAK1 closed template ma-l9b1f ([JAK2_20261014_115511](JAK2/runs/JAK2_20261014_115511)) | **closed**, drifts slightly towards Shan's JAK2 model (6.6–6.8 Å) |

- **MSA depth decides the result when there's no template.** The deep MSA gives a confident open structure;
  the shallow MSA gave the FERM-bound, low-confidence structures.
- **A template overrides that.** It can force either state.
- **Neither setting gives both states in one run.** The deep MSA gives a stable open JAK1; the closed state
  only came from a closed template.
