# JAK3 depth profile complete; TYK2 template assay abandoned (20261016_193000)

## JAK3 wild type: a sharp switch between two MSA depths

| MSA | seeds | final FERM–JH1 (Å) | state | run |
|---|--:|---|---|---|
| 512/8192 | 8 | 94 ×8 | **all open** | [JAK3_20261016_130116](JAK3/runs/JAK3_20261016_130116/conclusions.md) |
| **256/1024** | 16 | **94 ×15, 43 ×1** | **15/16 open** | [JAK3_20261016_172413](JAK3/runs/JAK3_20261016_172413/conclusions.md) |
| 128/512 | 16 | 42–56 | **all compact/closed** | [JAK3_20261016_125830](JAK3/runs/JAK3_20261016_125830/conclusions.md) |

The switch is **sharp**: 16/16 compact at 128/512, 15/16 open one step deeper. There is no broad
bistable regime — unlike JAK2, which was genuinely mixed at 512/8192 (7 closed / 7 open). The single
compact seed at 256/1024 shows the closed basin is still reachable there, just rare.

**Consequence:** 128/512 is the only usable depth for JAK3 mutation work, because it is the only depth
where wild type sits entirely in one state and a mutation has somewhere to go. Every JAK3 mutant in this
campaign is run there.

## JAK3 mutations at 128/512 — two opposite effects

Mann-Whitney on the 16 final FERM–JH1 values per run (threshold-free; preferred over the earlier Fisher
test on an arbitrary cutoff):

| | median | max | vs wild type |
|---|--:|--:|---|
| wild type | 50.5 | 56 | – |
| **M592F** | 55.0 | **97** | **p = 0.011, more extended** |
| **A573V** | **42.0** | 52 | **p = 0.0020, more compact** |

M592F (the JAK2 V617F / JAK1 V658F equivalent position) drives 5/16 seeds into the **open** arrangement,
3.3 Å from the JAK1 open model — the same state wild type adopts spontaneously at full MSA depth.
A573V tightens the compact state instead.

**Correction recorded:** A573V is **not** the reported activating allele. JAK3 has adjacent alanines at
572 and 573, and the literature mutation is **A572V** (Walters et al., Cancer Cell 2006). The earlier
variant list in this project recorded A573V and the residue identity check passed, because alanine
genuinely sits at 573. A572V is now running. Details in [mutation_analysis.md](mutation_analysis.md).

## TYK2: first run done, and the template assay does not work

[TYK2_20261016_130845](TYK2/runs/TYK2_20261016_130845/conclusions.md) — wild type, 4OLI as template in
recycles 1–3 then released, MSA 128/512, 16 seeds. Template mapped correctly (539 residues, 99.6 %).

**All 16 seeds stayed 1.4–1.9 Å from 4OLI through every template-free recycle.** Nothing moves after
release, so the assay has no dynamic range and cannot distinguish any mutant from wild type. Either the
basin is simply deep, or the `--template_recycles` release is not taking effect; the trajectories show no
discontinuity at recycle 3→4, which mildly favours the latter.

AF2 TYK2 (FERM–JH1 39.7 Å) and 4OLI (JH2–JH1 39.0 Å) are both compact and ~2 Å apart, so **TYK2's default
predicted state is already the closed one** and the template adds nothing. The TYK2 queue is rebuilt
around free prediction: wild type and **P982A** at 128/512, then at 512/8192, 8 seeds each.

The planned JAK3 ma-l9b1f release test has been dropped for the same reason.
