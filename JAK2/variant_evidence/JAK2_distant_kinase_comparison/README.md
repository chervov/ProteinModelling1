# JAK2 variant comparisons outside the JAK family

Human proteins: JAK2 O60674; SRC P12931; ABL1 P00519 (1a numbering); EGFR P00533; PTK2/FAK Q05397. The full set of 24 changes includes the two parts of the S755R/R938Q cis allele. The table has one row per input and target (96 rows). No ClinVar classification transfers across genes.

Unconstrained alignments are domain-local Smith-Waterman (BLOSUM62, gap open/extension 10/0.5 primary, 12/0.5, 10/1, 14/1 for sensitivity). Primary FASTAs use one-based inclusive coordinates in headers. For JH1/JH2 an additional alignment used global BLOSUM62 with affine penalties 10/0.5 within segments anchored at the beta3 lysine, gatekeeper and DFG/DPG aspartate. JAK2 JH1 K882/M929/D994; JH2 K581/Q626/D699; SRC K298/T341/D407; ABL1 K271/T315/D381; EGFR K745/T790/D855; PTK2 K454/M499/D564. JAK2 E846 is in the N-terminal extension, included in the JH1 window. JH2 is compared to an active kinase fold in the targets. Positions in loops and extensions are provisional even when gap penalties agree. For SH2, inspect the FLVRES motif. For FERM, FAK has a homologous domain but this sequence alignment does not establish equivalence for the six input sites. No structural superpositions were performed.

Evidence inspection used targeted searches of indexed primary literature and ClinVar by gene and protein change, with follow-up for selected same-site alleles. Not a bulk ClinVar release join. VUS = uncertain significance. Computed mutational landscapes were not counted as patient observations. Some alleles are reachable only via secondary indexes; the table marks these.
