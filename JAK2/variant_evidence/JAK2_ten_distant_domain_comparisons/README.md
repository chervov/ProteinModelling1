Ten JAK2 variants across more distant human proteins
==================================================
This selected panel contains 12 serine/threonine or dual-specificity kinases, 4 non-kinase SH2 proteins (two with tandem SH2 domains), and 5 non-kinase FERM proteins. It is not ranked or proteome-wide. Coordinates use the exact KEGG protein sequences supplied in seq.json. For each gene see source_sequences.tsv.

Start with evidence.tsv. The methods do not equate a projection, a patient observation, a database classification and a measured phenotype. P37A, F240V and H380Y have no defensible transfer to the five non-kinase FERM sequences. G571R maps to a loop with inconsistent register. For V1110E all eight BRAF sequence alignments select R701; there is no evidence here for an equivalent activating Val-to-Glu allele. For I1065T, BRAF I659T exists in a variant index, but Y656 is an alternative mapping. R426X denotes a premature stop. ClinVar classifications belong to the target protein and specific allele, not JAK2.

Reproduction: put seq.json and run.js together, then run node run.js. Input source and target coordinates count the initiator methionine. Each local Smith-Waterman comparison uses BLOSUM62 and affine gap settings (10,0.5), (12,0.5), (10,1), (14,1); these four settings are repeated with motif anchors. For kinase domains the anchors are the ATP-site lysine and the DFG-family motif aspartate. SH2 uses the conserved phosphate-binding arginine, with the two copies aligned separately when present. FERM uses no anchor so its two sets of four are identical. Kinases were compared separately to JAK2 JH1 and JH2. JH2 is regulatory. No 3D superpositions were performed, and distal loops should not be interpreted as structure-verified. The default FASTAs use anchored 10/0.5. The raw default projections are retained to show precisely where sequence alignment fails. In particular, do not use raw FERM projections as observations.

Clinical and experimental search: targeted exact-allele queries, accessible gene tables from Sugi (ClinVar index), Japan Cancer Genome Atlas, and CanProVar, with primary record/paper follow-up. No-hit, inaccessible, and unindexed data are not evidence of absence. Allele-specific activity/abundance scores could not be recovered from the interactive UW MAPK atlas in this analysis; none were imputed. Curated evidence contains the supported claims and source links. db_coverage.tsv lists site-level index leads as reported by source, including synonymous records; verify isoform and underlying record for reuse.
